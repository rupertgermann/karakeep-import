## Mandatory coding guidelines

Before writing, reviewing, or refactoring code, read and follow
`.agents/skills/karpathy-guidelines/SKILL.md`. This requirement is mandatory
for all agents working in this repository.

Before implementing any feature, bug fix, or other behavior change, read and
follow `.agents/skills/tdd2/SKILL.md`. Use its red-green cycles and complete its
constraint gauntlet before considering the work finished. This requirement is
mandatory for all agents working in this repository.
