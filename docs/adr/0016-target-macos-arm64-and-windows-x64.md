# Target macOS arm64 and Windows x64

The MVP will ship an arm64 app for macOS 14.8.9 or newer on Apple Silicon,
plus an x86-64 installer for Windows 10 version 1803 or newer and Windows 11.
Native Windows ARM64 and packaged Linux releases are deferred.
This bounds the bundled Field Theory and Node sidecar matrix while covering the
requested desktop platforms.
