# Choose source default tags in Settings

The library owner chooses source tags in Settings. The `twitter` and
`fieldtheory` settings apply to X bookmarks and Field Theory JSONL files. The
`chrome` setting applies to Chrome bookmark files.

All three settings start unchecked. The transfer review's **Attach source
tags** option controls whether the current run uses the applicable tags from
Settings. The separate **Attach tags from the export** option covers tags
carried by the source. [Folder mapping](0008-map-x-folders-to-karakeep-tags.md)
