# Domain Docs

This is a single-context repository.

Before exploring, read the root `CONTEXT.md` and relevant decisions under
`docs/adr/` when they exist. Their absence is not an error.

Use terminology defined by `CONTEXT.md` in issues, tests, designs, and
implementation work. Avoid synonyms that the glossary rejects.

If proposed work conflicts with an existing architectural decision, identify
the conflict explicitly instead of silently overriding it.
